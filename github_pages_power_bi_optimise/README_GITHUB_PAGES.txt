PUBLICATION DU SITE AVEC GITHUB PAGES

Contenu du dossier
- index.html : page d'accueil de la mini-formation
- assets/formation-power-bi.mp4 : vidéo du cours
- ressources/support-power-bi.pdf : support PDF
- ressources/donnees-exercice.xlsx : fichier Excel d'exercice

ETAPES
1. Connectez-vous à GitHub et créez un dépôt public, par exemple mini-formation-power-bi.
2. Décompressez ce dossier sur votre ordinateur.
3. Dans le dépôt GitHub, choisissez Add file > Upload files.
4. Téléversez le contenu du dossier (index.html, assets, ressources et README).
5. Ouvrez Settings > Pages.
6. Dans Build and deployment, choisissez Deploy from a branch.
7. Choisissez la branche main et le dossier /(root), puis cliquez Save.
8. Attendez la publication. GitHub affichera l'adresse du site dans Settings > Pages.

IMPORTANT
- Le site doit garder exactement cette structure de dossiers pour que la vidéo et les ressources fonctionnent.
- Vérifiez le site publié sur ordinateur et mobile.
- Le dépôt doit être public pour utiliser GitHub Pages gratuitement avec GitHub Free.
- Ne publiez aucune donnée confidentielle ou document appartenant à une entreprise.
- Le lien de formation à mettre dans le bouton START COURSE de la newsletter sera l'URL GitHub Pages affichée par GitHub.
